# API reference (planned)

> Status: **planned**. Final, always-current documentation is generated by
> FastAPI (OpenAPI) at `http://localhost:8000/docs`. This page explains the
> intent of each endpoint; names may change during implementation.

| Endpoint | Offers | Version |
|----------|--------|---------|
| `GET /api/health` | Check the API is running. **Available now.** | - |
| `GET /api/vulnerabilities` | Paginated list. Query params: `added_from`, `added_to`, `technology`, `vendor`, `product`, `min_cvss`, `min_epss`, `ransomware`, `q` (free text), `page`, `page_size`. | v1a |
| `GET /api/vulnerabilities/{cve_id}` | Full detail of one CVE. Returns 404 if unknown. | v1a |
| `GET /api/technologies` | Technologies loaded from `technologies.yaml`, to fill the filter. | v1a |

Package vulnerabilities from OSV and GitHub (v1b) will be exposed through the
same vulnerability endpoints, with their source indicated.
