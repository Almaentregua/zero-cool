# 2026-11-04

## Investigations: design
- What: design draft (`docs/technical/design/cve-research.md`), ADR 0004 (accepted), `scope.md` updated.
- Decisions: any CVE can be investigated (on-demand fetch outside KEV); source plugins; reports are snapshots with refresh; Markdown notes; first new sources CVE.org + Vulnrichment + CWE.
- Requirement added by the user: sources must be very clear in the report (one block per source with origin link, time and status; checked-but-empty sources listed; values never merged).

## Investigations step 1: report tables
- What: `Report`, `ReportCve`, `ReportSourceResult` models (created by `create_all`, no migration needed), `test_report_models.py` (5 tests), `data-model.md`.

## Investigations step 2: source interface and runner
- What: `research/base.py` (`ResearchSource`, `Fetched`, `SourceResult`, CVE id validation), `research/runner.py` (parallel run, 15 s timeout per source, TTL cache, isolated failures), `research-sources.md`, 10 tests (142 total).
- Decision: no registry yet; it arrives with the first real sources in step 3 (YAGNI).

## Investigations step 3: first sources
- What: adapters `kev`, `nvd`, `epss`, `osv` in `research/adapters/`, `registry.build_sources`, 9 tests including an end-to-end run with mocked HTTP (151 total).
- Decision: NVD always live with a 24 h cache (no "stored first" path).

## Investigations step 4: CVE.org + Vulnrichment
- What: `sources/cve_org.py` (parser + client with 60 s memo), adapters `cve_org` and `vulnrichment`, 2 real record fixtures (Log4Shell, CVE-2023-4863), 12 tests (164 total).
- Verified live first: record shape, CISA-ADP container (CVSS, SSVC, KEV, CWE), 404 for unknown ids.
- Decision: two blocks from one request, because CNA and CISA are different authors.

## Investigations step 5: MITRE CWE
- What: `sources/cwe.py` (client with 24 h memo; weakness and category parsers), adapter `cwe` (reads CWE ids from the CVE record), fixtures for CWE-502 and category CWE-16, 12 tests (176 total).
- Verified live first: REST API `cwe-api.mitre.org/api/v1`; `/cwe/{id}` returns only the type; unknown ids give 404.
- Decision: the block lists who named each CWE (CNA, CISA); unknown ids show no text.

## Investigations step 6: research endpoint
- What: `GET /api/research/{cve_id}?refresh=`, `api/research.py`, dependencies `get_research_sources` / `get_result_cache`, 4 tests (180 total), `api.md`.
- Verified live with the real sources: CVE-2021-44228 returns 7 blocks all `ok` in about 5 s (first call); an unknown CVE returns `no_data` in every block; an invalid id returns 422.
- First step where something can be tried: `make backend`, then `/docs`.

## Investigations step 7: report endpoints
- What: `api/reports.py` (create, list, open, patch, refresh, delete), `research/diff.py`, CORS widened to POST/PATCH/DELETE, 19 tests (199 total), `api.md`, ADR 0004 consequences.
- Decisions: max 10 CVEs per report; a failed refresh keeps the previous block (`refresh_failed`); diff returned once, not stored; names of sources are looked up from the registry when a report is opened.
- Verified live on a COPY of the database: create with 2 CVEs (14 blocks, 5 s), refresh (no changes), delete. The real database was not touched.

## Investigations step 8: frontend page
- What: `/investigations` (`InvestigationPage.tsx`), per-source views (`SourceData.tsx`), `fetchResearch`, `parseCveIds`, `formatDateTime`, menu entry, CSS; 8 tests (41 frontend total); `frontend.md` and functional `pages.md`.
- Decisions: CVE ids in the URL; one request per CVE; summary of sources with status as text (not only color); generic fallback view for sources without one.
- Verified: tsc, oxlint, Vitest. Not looked at in a browser yet by me.

## Investigations step 9: reports in the UI
- What: "Save as report" on `/investigations`; `/reports` list and `/reports/:id` (notes with edit and preview, status, rename, add/remove CVEs, refresh with changes, delete); extracted `SourceBlock`, `Notes`, `notesMode`, `reportFormat`; 18 tests (59 frontend total); `frontend.md`, functional `pages.md`.
- Dependency added (approved): `react-markdown` ^10.1.0, justified in `frontend.md`. Notes can be shown as Markdown or plain text; the choice is a display preference in localStorage.
- Verified: tsc, oxlint, Vitest. Not looked at in a browser yet by me.

## Investigations step 10: documentation pass
- What: glossary (investigation, report, snapshot, CNA, ADP, Vulnrichment, SSVC, CWE, Markdown), functional `sources.md` and `README.md`, root `README.md`, `scope.md` status, design doc rewritten as "as built + roadmap".
- Investigations first iteration is complete (10 of 10 steps).
- Ideas for next: more sources (Exploit-DB, Metasploit, Nuclei, PoC-in-GitHub, distro trackers, VulnCheck), persisted refresh diff and persistent cache, export, a "why urgent" summary of facts.
